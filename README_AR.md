# مُتابع المعاملات — حزمة التشغيل

هذه الحزمة تحتوي على تطبيق عربي لإدارة واستعلام المعاملات، ويعمل بواجهة RTL على الكمبيوتر والهاتف عند تشغيله من متصفح Chrome.

## تشغيل سريع على Windows

1. فك ضغط الملف كاملًا.
2. افتح مجلد الحزمة.
3. انقر مرتين على الملف `تشغيل-النظام.bat`.
4. ستظهر نافذة سوداء تبقى مفتوحة؛ لا تغلقها أثناء استخدام النظام.
5. افتح Chrome واكتب:

   `http://localhost:8000`

6. يمكن بعد ذلك اختيار «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».

يتطلب التشغيل وجود Python 3 على الكمبيوتر. إذا لم يكن مثبتًا، ثبته من الموقع الرسمي python.org، مع تفعيل خيار Add Python to PATH.

## تشغيل على Linux أو macOS

افتح Terminal داخل مجلد الحزمة، ثم نفّذ:

```bash
./تشغيل-النظام.sh
```

ثم افتح Chrome على:

`http://localhost:8000`

أو نفّذ يدويًا:

```bash
python3 -m http.server 8000 --directory dist
```

## تشغيل من المصدر وإعادة البناء

يتطلب Node.js 18 أو أحدث:

```bash
npm install
npm run build
python3 -m http.server 8000 --directory dist
```

## وظائف النظام

- لوحة مؤشرات تفاعلية.
- بحث برقم القيد أو الموضوع أو المستفيد أو رقم الهاتف أو رقم الحركة أو اسم الجهة.
- ترتيب النتائج تصاعديًا حسب رقم الحركة.
- استيراد ملفات Excel بصيغ xlsx وxls وcsv.
- تصدير كل البيانات أو نتائج البحث إلى Excel.
- تعديل السجلات وحفظها محليًا.
- العمل دون اتصال بعد فتح النظام مرة واحدة وتثبيته من Chrome.

## ملاحظة مهمة عن مشاركة البيانات

البيانات محفوظة محليًا على كل جهاز. لمشاركة آخر نسخة مع شخص آخر، استخدم زر «تصدير» ثم أرسل ملف Excel له، وبعدها يستورد الملف من زر «استيراد Excel».

لا تفتح ملف `dist/index.html` بالنقر المباشر؛ استخدم ملف التشغيل أو خادمًا محليًا، لأن التطبيق يحتاج خادم HTTP حتى يعمل تحميل البيانات وService Worker بشكل صحيح.
